# かんじ書き取りテスト作成

小学生向けの漢字書き取りテスト(紙に鉛筆で書くタイプ)を作れる静的Webアプリ。
学年(1〜6年)を横断して、漢字を1文字単位で自由に選び、ひらがな→漢字の問題を作成・印刷できる。

## 使い方

1. `index.html` をブラウザで開く(ビルド不要)
2. 出したい漢字にチェックを入れる(学年フィルタ・検索で絞り込み可)
3. 「テストを作成する」を押す
4. 「印刷する / PDFで保存する」で印刷、またはPDF保存(最後のページは解答一覧)

## 収録データ

`data.js` に学年ごと代表的な20字ずつ、計120字を収録(各2語)。
本物の学年別漢字配当表(1006字)全部ではなく代表的なセット。
追加したい場合は `data.js` の配列に同じ形式でエントリを足すだけで反映される。

```js
{ kanji: '一', grade: 1, words: [ { reading: 'ひとつ', answer: '一つ' }, { reading: 'いちねん', answer: '一年' } ] }
```

## ローカルで確認

```sh
python3 -m http.server 8000
# http://localhost:8000/index.html を開く
```

## GitHub Pagesへのデプロイ

1. このディレクトリの内容をGitHubリポジトリにpush(ビルド不要、静的ファイルのみ)
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」にし、ブランチ `main` / フォルダ `/ (root)` を選択
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
